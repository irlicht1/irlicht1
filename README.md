## ❓ FAQ

### Q: Ошибка "'pip' is not recognized"
**A:** Используйте команду `py -m pip install` вместо `pip install`, или переустановите Python с галочкой "Add to PATH".

### Q: Файлы не переименовываются
**A:** Проверьте:
1. Закрыты ли файлы в других программах
2. Есть ли у вас права на запись в папке
3. Совпадает ли количество файлов и имён в таблице

### Q: Программа зависает при запуске
**A:** Попробуйте запустить из командной строки:
```bash
python renamer_gui.py
```

### Q: Как добавить другие расширения кроме .mp4?
**A:** В коде найдите строку `+ ".mp4"` и замените на нужное расширение.

# 📁 ВЕРСИИ ПРОГРАММЫ

## Версия 1.0 - Базовая

### 📋 Описание
Первая версия программы с поддержкой двух столбцов в таблице: старые и новые имена файлов.

### 📁 Файлы
- `renamer_gui_v1.py` - основной файл программы
- `start_v1.bat` - скрипт для запуска

### ⚙️ Функции
- **Два столбца**: старые и новые имена
- **Поиск файлов** по именам из первого столбца
- **Добавление .mp4** к новым именам
- **Проверка существования** файлов

### 🚀 Использование
1. Создайте таблицу с колонками `old_name` и `new_name`
2. В `old_name` укажите текущие имена файлов
3. В `new_name` укажите новые имена (без .mp4)
4. Запустите программу и выберите таблицу и папку

### 📊 Пример таблицы
```csv
old_name,new_name
video1.mp4,фильм_2024
document.pdf,отчет_январь
data.xlsx,статистика
```

## Версия 3.0 - Обработка дубликатов

### 📋 Описание
Версия с автоматической обработкой дублирующихся имён в таблице.

### 📁 Файлы
- `renamer_gui_v3.py` - основной файл программы
- `start_v3.bat` - скрипт для запуска

### ⚙️ Функции
- **Автоматическая нумерация** дубликатов
- **Детальный лог** дублирующихся имён
- **Уникальные имена** гарантированы
- **Расширенная статистика** выполнения

### 🔄 Изменения по сравнению с v2.0
1. Добавлена обработка одинаковых имён в таблице
2. Дубликаты получают номера: (1), (2), (3)...
3. Улучшен лог с информацией о дубликатах

### 🚀 Использование
1. Создайте таблицу (дубликаты разрешены)
2. Программа автоматически добавит номера к повторяющимся именам
3. Первое вхождение имени остаётся без номера

### 📊 Пример работы
**Таблица:**
```
фильм
урок
фильм
отчет
фильм
```

**Результат:**
- `фильм.mp4`
- `урок.mp4`
- `фильм (1).mp4`
- `отчет.mp4`
- `фильм (2).mp4`

## Версия 4.0 - Сортировка по дате создания

### 📋 Описание
Версия с сортировкой файлов по дате и времени создания.

### 📁 Файлы
- `renamer_gui_v4.py` - основной файл программы
- `start_v4.bat` - скрипт для запуска

### ⚙️ Функции
- **Сортировка по дате создания** (от старых к новым)
- **Отображение дат** в логе выполнения
- **Сохранение хронологического порядка**
- **Все функции версии 3.0**

### 🔄 Изменения по сравнению с v3.0
1. Изменён алгоритм сортировки файлов
2. В логе отображаются даты создания файлов
3. Обновлён интерфейс с информацией о новом порядке

### 🚀 Использование
1. Создайте таблицу с новыми именами
2. Файлы будут отсортированы по дате создания
3. Самый старый файл получит первое имя из таблицы

### 📊 Пример работы
**Файлы в папке:**
1. `video_2022.mp4` (создан 2022-05-15)
2. `lesson_2023.avi` (создан 2023-12-10)
3. `doc_2024.pdf` (создан 2024-01-20)

**Таблица:**
```
старый_фильм
новый_урок
актуальный_доклад
```

**Результат:**
1. `video_2022.mp4` → `старый_фильм.mp4`
2. `lesson_2023.avi` → `новый_урок.mp4`
3. `doc_2024.pdf` → `актуальный_доклад.mp4`

### ⏱️ Особенности сортировки по дате
- Используется время создания файла (`os.path.getctime()`)
- Сортировка от **старых к новым**
- В логе отображаются даты для наглядности
- Идеально для хронологического упорядочивания

# 🛠️ Сборка программы в EXE

## Создание исполняемого файла

### Установка PyInstaller
```bash
py -m pip install pyinstaller
```

### Сборка EXE файла
```bash
# Для версии 4.0
pyinstaller --onefile --name "FileRenamer_v4" --icon=icon.ico renamer_gui_v4.py

# Без консоли (только GUI)
pyinstaller --onefile --windowed --name "FileRenamer_v4" --icon=icon.ico renamer_gui_v4.py
```

### Параметры сборки
| Параметр | Описание |
|----------|----------|
| `--onefile` | Создать один исполняемый файл |
| `--windowed` | Без консольного окна (только GUI) |
| `--name` | Имя выходного файла |
| `--icon` | Иконка программы |
| `--add-data` | Добавить дополнительные файлы |

### Структура после сборки
```
dist/
└── FileRenamer_v4.exe  # Исполняемый файл
build/                  # Временные файлы сборки
```
